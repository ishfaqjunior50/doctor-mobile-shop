DOCTOR MOBILE SHOP WEBSITE - EASY SETUP

ZIP extract karne ke baad doctor_mobile_shop_website folder ko VS Code mein File > Open Folder se kholein. index.html par right-click > Open with Live Server karein (agar Live Server extension installed hai).

FILES:
index.html = home page
style.css = design/colors/layout
script.js = product data, search, cart aur WhatsApp order
mobiles.html, watches.html, books.html, sports.html = alag category pages
all-products.html = Shop Now / View All Products
checkout.html = cart, customer details, payment preference, WhatsApp order
login.html = demo login/register interface (real secure login nahin)
INTEGRATION-GUIDE-UR.txt = Roman Urdu mein complete setup aur integration guide

PRODUCTS:
script.js mein PRODUCTS list ke product names, brands, prices aur image URLs sample hain. Apne asli products ke mutabiq update karein.
